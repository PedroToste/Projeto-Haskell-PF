# Sistema de Gestão de Trotinetes (Haskell)

Versão inicial do projeto focada nos fundamentos de programação funcional, incluindo modelos de domínio, funções puras e recursão.

## Como compilar e executar (GHCi)
1. Abrir o terminal na diretoria do projeto.
2. Carregar o módulo principal: `ghci Main.hs`
3. Executar a demonstração digitando: `main`
